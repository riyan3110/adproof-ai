GUIDE / 01

Everything you need.
Nothing extra.

AdProof AI memeriksa materi iklan menggunakan Meta Muse Spark, mengedit gambar menggunakan Muse Image, kemudian mengaudit hasilnya lagi.

01 / Mulai

  1. Buka Creative Lab.
  2. Unggah gambar PNG/JPG/WebP (maksimum 6 MB).
  3. Isi nama produk dan fakta produk yang dapat dibuktikan.
  4. Tekan Run audit untuk analisis aktual dengan Meta.
  5. Gunakan Improve creative untuk menghasilkan versi gambar baru, kemudian Verify revision.

02 / Apa yang diperiksa

Model meninjau konsistensi klaim dengan data produk, keterbacaan, hierarki visual, dan ajakan bertindak. Skor 0–100 adalah estimasi AI untuk membantu perbandingan, bukan hasil uji laboratorium atau sertifikasi kepatuhan.

Temuan audit mencantumkan kategori, tingkat urgensi, bukti yang terlihat, dan saran. Klaim yang tidak didukung fakta akan ditandai perlu verifikasi; model tidak boleh langsung menyebutnya bohong.

03 / Privasi

Gambar dikirim melalui backend ke Meta Model API untuk diproses, tetapi tidak disimpan ke database oleh AdProof AI. Data gambar hanya berada dalam memori saat request. Jangan unggah data pribadi atau rahasia. Kebijakan pemrosesan data Meta tetap berlaku saat menggunakan layanan mereka.

API key hanya berada pada variabel lingkungan backend. Jangan menyimpan API key di browser, commit GitHub, atau HTML.

04 / Instalasi & deploy

cp .env.example .env
# isi MODEL_API_KEY di .env
node --env-file=.env server.mjs
# buka http://localhost:3000

Memerlukan Node.js 20+. Tidak menggunakan database, frontend framework, ataupun paket npm tambahan. Untuk deployment gunakan hosting Node.js yang menjalankan server HTTP ini, dan konfigurasi MODEL_API_KEY sebagai secret. Hosting statis saja tidak cukup karena API key tidak boleh diekspos.

Jalankan npm run check untuk validasi JavaScript dan pengujian lokal.

05 / Batasan

AI bisa keliru dalam membaca teks kecil, mengenali label, atau memberi skor. Gambar hasil Muse Image dapat mengubah detail yang tidak diminta atau keliru menggambar teks. Periksa hasil secara manual sebelum menerbitkan materi iklan.

Penggunaan model memerlukan saldo dan akses Meta Model API. Aplikasi tidak menyediakan mode analisis palsu ketika API key belum diatur. Belum termasuk autentikasi pengguna, sistem pembayaran, atau penyimpanan permanen.
