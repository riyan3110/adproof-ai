GUIDE / 01

Everything you need.
Nothing extra.

AdProof AI memeriksa materi iklan menggunakan Meta Muse Spark, mengedit gambar menggunakan Muse Image, kemudian mengaudit hasilnya lagi.

01 / Mulai

  1. Buka Creative Lab.
  2. Unggah gambar PNG/JPG/WebP (maksimum 6 MB).
  3. Isi nama produk dan fakta produk yang dapat dibuktikan.
  4. Tekan Run audit untuk analisis aktual dengan Meta.
  5. Gunakan Improve creative untuk menghasilkan versi gambar baru, kemudian Verify revision.

02 / Apa yang diperiksa

Model meninjau konsistensi klaim dengan data produk, keterbacaan, hierarki visual, dan ajakan bertindak. Skor 0–100 adalah estimasi AI untuk membantu perbandingan, bukan hasil uji laboratorium atau sertifikasi kepatuhan.

Temuan audit mencantumkan kategori, tingkat urgensi, bukti yang terlihat, dan saran. Klaim yang tidak didukung fakta akan ditandai perlu verifikasi; model tidak boleh langsung menyebutnya bohong.

03 / Privasi

Gambar dikirim melalui backend ke Meta Model API untuk diproses, tetapi tidak disimpan ke database oleh AdProof AI. Data gambar hanya berada dalam memori saat request. Jangan unggah data pribadi atau rahasia. Kebijakan pemrosesan data Meta tetap berlaku saat menggunakan layanan mereka.

API key hanya berada pada variabel lingkungan backend. Jangan menyimpan API key di browser, commit GitHub, atau HTML.

04 / Instalasi & deploy

cp .env.example .env
# isi MODEL_API_KEY di .env
node --env-file=.env server.mjs
# buka http://localhost:3000

Memerlukan Node.js 20+. Tidak menggunakan database, frontend framework, ataupun paket npm tambahan. Untuk deployment gunakan hosting Node.js yang menjalankan server HTTP ini, dan konfigurasi MODEL_API_KEY sebagai secret. Hosting statis saja tidak cukup karena API key tidak boleh diekspos.

Untuk demo publik yang memakai kuota Meta berbayar, tetapkan DEMO_ACCESS_CODE sebagai secret di hosting Node.js (bukan di Git atau browser). Selama variabel itu terisi, POST /api/audit dan POST /api/improve menolak request tanpa kode yang benar (401/403) sebelum memanggil Meta. Browser hanya menanyakan kode setelah server memintanya, menyimpannya di sessionStorage saja, dan tidak pernah menampilkannya di laporan. Kode ini hanya gerbang demo ringan, bukan pengganti batasan belanja atau kontrol akses penyedia.

Jalankan npm run check untuk validasi JavaScript dan pengujian lokal.

05 / Batasan

AI bisa keliru dalam membaca teks kecil, mengenali label, atau memberi skor. Gambar hasil Muse Image dapat mengubah detail yang tidak diminta atau keliru menggambar teks. Periksa hasil secara manual sebelum menerbitkan materi iklan.

Penggunaan model memerlukan saldo dan akses Meta Model API. Aplikasi tidak menyediakan mode analisis palsu ketika API key belum diatur. Belum termasuk autentikasi pengguna, sistem pembayaran, atau penyimpanan permanen.

06 / Deploy ke Vercel (Hobby, gratis)

Repository ini siap diimpor ke Vercel tanpa mengubah UI maupun server lokal. File statis disajikan dari public/ (/, /app, /docs, /styles.css, /app.js), sedangkan /api/health, /api/audit, dan /api/improve berjalan sebagai Functions di api/ yang memakai ulang handler dan integrasi Meta API yang sama — tanpa duplikasi logika bisnis maupun secret di browser.

Batasan paket Hobby yang ditangani: request DAN response Function maksimal 4,5 MB, sehingga browser mengompresi gambar (sisi maks. 1280px, kualitas adaptif, total request sekitar 3,6 MB) sebelum dikirim; jika gambar hasil Muse Image melebihi batas respons, server mengembalikan error 502 yang jelas dan meminta gambar sumber yang lebih kecil — tidak pernah memotong gambar diam-diam atau mengembalikan hasil palsu. Durasi Function dibatasi 60 detik (maxDuration di vercel.json); jika Improve creative kehabisan waktu, ulangi request. Tidak ada blob storage atau layanan berbayar tambahan.

  1. Di Vercel pilih Add New… → Project → Import lalu pilih repository GitHub AdProof AI (paket Hobby tidak memerlukan kartu kredit).
  2. Pada Environment Variables tambahkan MODEL_API_KEY (wajib, secret Meta) dan DEMO_ACCESS_CODE (disarankan untuk demo publik; tanpa kode yang benar API menolak 401/403 sebelum kuota Meta terpakai). Opsional: META_MODEL.
  3. Klik Deploy. Server lokal (node server.mjs) tetap tidak berubah untuk development.

Deployment live belum diuji oleh Muse Code; pengujian lokal memakai handler api/ yang sama (adapter produksi) dan npm run check.

07 / Akses juri

Halaman home, walkthrough, studio, dan docs terbuka tanpa login. Namun POST /api/audit dan POST /api/improve tetap membutuhkan DEMO_ACCESS_CODE (server-side, tidak ada di Git/browser). Juri menekan tombol ◈ di studio atau menunggu prompt otomatis, menempel kode sekali per sesi (hanya sessionStorage, tidak persisten).

Bagikan kode hanya secara privat melalui kolom instruksi submission lomba. Jangan pernah menaruh kode di postingan X, README publik, issue GitHub, atau video demo.

08 / Opsi audit publik terbatas (default MATI)

Audit anonim berbayar nonaktif secara default dan tidak pernah memakai limit in-memory/IP-only atau rahasia di browser sebagai batas belanja. Untuk mengaktifkannya, konfigurasi backend KV atomik bersama (mis. Upstash/Vercel KV REST) sebagai secret server:

PUBLIC_ANON_AUDITS_ENABLED=true
QUOTA_KV_REST_URL=https://...upstash.io
QUOTA_KV_REST_TOKEN=...
PUBLIC_QUOTA_PER_USER_DAILY=3
PUBLIC_QUOTA_GLOBAL_DAILY=50

Server menjalankan satu EVAL Lua atomik yang memeriksa lalu menaikkan counter harian global DAN per-pengguna, selalu sebelum pemanggilan Meta. Tanpa backend yang dikonfigurasi (atau saat KV error), request anonim berbayar gagal tertutup (503). Jalur anonim hanya mencakup /api/audit; /api/improve tetap butuh kode. Limit in-memory per-IP hanya pertahanan lapis tambahan, bukan jaminan batas belanja global. Disarankan: aktifkan WAF/rate-limit tepi (mis. Vercel Firewall) dan tantangan bot (mis. CAPTCHA/Turnstile) di depan endpoint publik. Panggilan nyata memakai kredit Meta berbayar — tidak gratis/tidak terbatas.
