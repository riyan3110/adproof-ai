# Access and request lifecycle correction — 1 November 2026

Baseline: `efc0c08205718841b476acf55b824b5389d413f6` (PR #58).

## Corrected defects

- `verifyCode` referenced `pulse`, a variable defined only in the separate paid-request helper. Its `finally` threw after every access response, so even a correct server-verified code was discarded and reported as a connection failure. Access now cleans up only its own timeout. Incorrect-code feedback and saved-tab access restoration work again.
- Audit/localization/image request intervals were never cleared. Each completed request left a timer that could overwrite later Repair/Verify progress and accumulate in a long session. Each request now releases its timeout and progress interval on success, provider rejection, network failure, or abort. Elapsed time refreshes once per second in the selected language.
- Audit/Verify now replace the elapsed status with a completed or incomplete stage after the request settles.
- At 768 pixels the header's language, connection, access, and documentation controls overflowed by 11 pixels after access/audit status text changed. The tablet header now wraps within the available width and grows naturally; all controls remain visible.
- Switching languages after an audit left the compact report heading/counts in the old UI language. These interface labels now refresh without modifying the original model explanation, archived findings, images, or initiating any model request.
